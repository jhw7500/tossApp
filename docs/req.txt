수익 구조는 현재 토스 인앱 정책상 크게 광고 기반 수익과 직접 결제(토스페이) 방식이 가능한 것으로 확인했습니다.
(( 제가 생각하는 초기 방향은 광고보다는 직접 결제 방식입니다. ))

타로를 보는 흐름 중간에 광고가 노출되면 몰입이 끊길 가능성이 높아 보여서,
기본 리딩 이후 사용자가 자연스럽게 추가 질문을 하도록 유도하고,
해당 단계에서 결제로 연결하는 구조가 서비스 경험상 더 적합해보입니다.

이후 서비스 이용자가 충분히 늘어나고 콘텐츠가 확장된다면,
그때 광고형 콘텐츠나 별도의 무료 콘텐츠를 추가해 수익 구조를 넓히는 방향도 괜찮을 것 같습니다.

마지막으로 한 가지 가장 중요하게 봐주셨으면 하는 부분이 있습니다.

각 타로 카드에는 제가 직접 작성한 여러 개의 해석 데이터가 연결될 예정이고,

AI가 임의로 카드 의미를 새롭게 만들어내는 방식보다는
해당 카드에 연결된 해석들을 기반으로 질문의 맥락에 맞게 조합하고 해석하는 구조를 생각하고 있습니다.


즉,
“카드 1장 = 단일 해석”이 아니라
“카드 1장 = 여러 개의 해석 데이터”이고,
AI는 이 데이터를 기반으로 사용자 질문에 맞는 결과를 만들어주는 방식입니다.

이 부분이 서비스의 핵심 로직이라 개발 구조를 잡으실 때 꼭 고려 부탁드립니다.
